lesser.host control plane

Managed hosting, trust, safety, billing, and soul registry infrastructure for Lesser.

lesser-host provisions isolated AWS accounts for managed Lesser and Body instances, verifies release artifacts, publishes attestations, operates comms and billing surfaces, and anchors agent identity through the soul registry.

Read the docs View source

Multi-tenant isolation

Each managed instance is provisioned into its own AWS account. Host stores control-plane metadata, not tenant content.

Release verification

Lesser and Body artifacts are checksum-verified before the provisioning worker deploys them into tenant accounts.

Trust rigor

Instance APIs authenticate with bearer keys whose SHA-256 hashes are stored server-side. Raw keys are never retained.

Public surfaces

One first-party origin, three major surfaces

Control plane API

Operator and customer portal APIs for wallet login, WebAuthn, instance CRUD, provisioning, updates, billing, and setup.

/api/v1/* · /auth/* · /setup/*

Trust API

Public attestation reads plus instance-authenticated trust, preview, render, safety, and AI evidence services.

/.well-known/* · /attestations/*

Soul registry

On-chain ERC-721 identity, off-chain DynamoDB state, Safe-ready governance payloads, and public agent lookup APIs.

/api/v1/soul/*

Governance-first

CI-enforced rubric, evidence, and anti-drift discipline

The gov-infra/ rubric is a deterministic quality, security, compliance, and evidence system. Verifiers produce 0-or-full-points results and write evidence artifacts for review.

  • Strict single-origin CSP posture
  • Safe-ready mainnet on-chain governance
  • AGPL-3.0-only source discipline
  • No raw instance keys or tenant data in host
