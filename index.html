Repository Posture

The architectural invariants that define how lesser-host operates in production.

Boundary

Data Isolation

Host stores control-plane metadata only. Tenant content and user data stay strictly within the tenant's dedicated AWS account. The only exception is soul comm mailbox delivery artifacts, governed by an explicit ADR boundary.

Auth

Dual Auth Models

Wallet/WebAuthn sessions for human operators and portal customers. SHA-256 instance-key hashes for machine-to-machine auth between managed instances and host APIs.

Delivery

Single Origin + CSP

Single-origin CloudFront distribution with strict Content-Security-Policy. Zero inline scripts, zero inline styles, zero third-party script dependencies on operator surfaces.

Runtime

AppTheory Framework

All Go services use github.com/theory-cloud/apptheory for HTTP routing and Lambda dispatch. CDK infrastructure uses AppTheory CDK patterns. Go, TypeScript, and Python runtimes stay in lockstep on shared Lambda contracts.

Verification

Consumer Release Verification

Every managed deployment downloads, manifest-checks, and SHA-256 verifies Lesser and lesser-body release assets before CodeBuild execution. Uncertified assets never reach a managed instance.

License

AGPL + CSP Discipline

AGPL-3.0-only. No proprietary blobs, no secret material in git, deterministic governance verifiers under gov-infra/ that fail closed.

System Architecture

The host stack is AWS CDK managed and deployed through the AppTheory contract. Public traffic lands at one CloudFront distribution; tenant workloads run outside the host account boundary in per-slug managed accounts.

01

CloudFront entry

Static web assets and API paths share a first-party origin to preserve a strict no-inline CSP posture.

02

Control and trust APIs

/api/*, /auth/*, and /setup/* route to the control-plane API; /.well-known/* and /attestations* route to the trust API.

03

State and queues

DynamoDB, S3, SQS, KMS, SSM, and Secrets Manager back jobs, attestations, release receipts, billing state, and operational evidence.

04

Managed account runner

The provisioning worker invokes CodeBuild to deploy verified Lesser and lesser-body releases into the target tenant account, with every Managed Instance in its own dedicated AWS account for blast-radius isolation.

Infrastructure Stack

Compute

Lambda

Go services deployed as Lambda functions behind API Gateway v2, with AppTheory universal Lambda dispatch for HTTP, SQS, and EventBridge.

CDN

CloudFront

Single distribution serving static assets and API routes with strict CSP headers and path-based origin routing.

State

DynamoDB + S3

Single-table design for instance state, jobs, attestations, and audit logs. S3 for artifacts, receipts, and registration packs.

Secrets

KMS + SSM

KMS for signing keys and encryption. SSM Parameter Store for cross-stack wiring. Secrets Manager for instance keys.

Trust API

The cmd/trust-api service provides the public trust surface: JWKS key publication, attestation reads, instance-key authenticated preview/scan/render/safety endpoints, and AI evidence workflows.

Public

JWKS & Attestations

Serves RS256 public keys at /.well-known/jwks.json and signed attestations at /attestations/{id}. Public endpoints (JWKS, attestations) are publicly cacheable with immutable TTLs. Preview, render, and AI endpoints require instance-key authentication. Attestation lookups by (instance_slug, actor_uri, object_uri, content_hash) tuple.

Instance-Auth

Preview & Render

Hardened URL fetching with SSRF protection (private IP/metadata blocking), redirect-safe canonicalization, and OG metadata extraction. Headless browser rendering for screenshot thumbnails and bounded text snapshots. All fetches respect time/byte/redirect limits.

Instance-Auth

Safety Scanning

Deterministic link safety checks (scheme/port analysis, shortener detection, punycode/homograph flags). Budget-gated — always returns "not checked due to budget" rather than blocking. Results deduplicate across instances via content-hash caching.

Instance-Auth

AI Evidence & Moderation

Multi-model claim verification with structured citations and confidence scores. Text and image moderation via AWS Comprehend, Rekognition, and LLM providers. Triggered on reports, always-on, or virality thresholds.

Managed Instance Provisioning

End-to-end provisioning of managed Lesser instances into dedicated AWS accounts. Each instance gets its own account, delegated DNS zone, verified Lesser + lesser-body deployment, and instance API keys.

1

Request & Allocate

User requests a slug (e.g. alice). Host creates a dedicated AWS account in the org or allocates from a pool. Validates account ID, email, and Organizations membership before persisting.

2

DNS Delegation

Creates a public Route53 hosted zone for slug.greater.website in the instance account. Delegates from the parent greater.website zone via NS record. All other records created by Lesser CDK stacks.

3

Deploy Lesser

Downloads and SHA-256 verifies the Lesser release assets. Runs lesser up via CodeBuild in the instance account with verified assets. Seeds admin wallet via lesser init-admin with structured EIP-191 consent.

4

Deploy lesser-body + MCP

Optionally deploys lesser-body (AgentCore MCP runtime) into the instance account. Wires POST /mcp/{actor} onto the instance API Gateway via SSM cross-stack parameters. Publishes /.well-known/mcp.json.

Services & Workers

All Go entrypoints live under cmd/. APIs use AppTheory HTTP runtime; workers consume SQS queues.

API

control-plane-api

Portal, operator, setup, wallet/WebAuthn auth, provisioning triggers, updates, billing, tips, and soul APIs. The central API surface for all host operations.

API

trust-api

Public trust surface, JWKS, attestation reads, instance-key auth, previews, safety, and AI evidence endpoints. All responses are publicly cacheable.

Worker

provision-worker

SQS-driven managed provisioning and update orchestration. Handles account vending, DNS delegation, CodeBuild invocation, release verification, and receipt ingestion. Supports retry with idempotency per slug.

Worker

render-worker

Headless browser rendering for preview thumbnails and bounded text snapshots. Manages artifact storage, scheduled retention sweeps (30d benign, 180d flagged), and render queue consumption.

Worker

ai-worker

Moderation scanning (text + image via Comprehend, Rekognition, LLM providers), safety analysis, evidence extraction with citations, claim verification with multi-model confidence scoring, and attestation signing.

Ingress

SES inbound mail bridge. Receives raw RFC 5322 messages from S3 events, parses them, and enqueues normalized communication:inbound payloads for comm-worker.

Worker

Outbound communication delivery for host-managed soul mailbox and body communication tools. Supports email (via Migadu), SMS, and voice channels with bounded content and delivery state tracking.

Worker

Scheduled reputation aggregation and signed reputation/validation root publication. Computes and publishes Merkle roots on-chain via ReputationAttestation and ValidationAttestation contracts.

Worker

cost-telemetry-worker

Periodic cost and usage telemetry aggregation. Feeds operator-visible managed-hosting economics dashboards with per-instance and aggregate cost data.

Portal & Billing

The self-serve customer portal and operator console, backed by the control-plane API. Wallet-based authentication with operator approval flow for new customers.

Self-Serve

Customer Portal

Wallet-based login (EIP-191 challenge-signature flow). Create and claim instance slugs. Configure previews, safety, attestations, and moderation per instance. View usage dashboards with cache-hit rates, budget status, and credit consumption.

Operator

Operator Console

Review and approve portal user registrations, vanity domain requests, and external instance registrations. Propose Safe multi-sig transactions for on-chain operations. Record execution results with full audit trail.

Payments

Stripe Billing

Credit purchasing via Stripe checkout. Payment method management for overage billing. Webhook-driven payment confirmation updates instance budgets. Stripe secret key and webhook signing secret stored in SSM SecureString parameters.

Audit

Audit Trail

All meaningful portal and operator actions write AuditLogEntry records. Includes instance creation, domain verification, provisioning jobs, user approvals, on-chain execution recording, and billing events.

Public Attestations

KMS-signed, publicly cacheable, offline-verifiable trust receipts. Bound to (instance_slug, actor_uri, object_uri, content_hash) so they never apply to quote posts or other tenants.

Endpoint

Public Keys (JWKS)

GET /.well-known/jwks.json — Returns RS256 public keys. Cacheable for 1 hour. kid is the KMS key ID.

Endpoint

Fetch by ID

GET /attestations/{id} — Returns the JWS, decoded header, and decoded payload. Served with Cache-Control: immutable until expiry.

Endpoint

Lookup by Tuple

GET /attestations?instance_slug=&actor_uri=&object_uri=&content_hash=&module=&policy_version= — Deterministic lookup by bound attributes.

Preview & Render Pipeline

Hardened link preview fetching and headless rendering. All external fetches are SSRF-protected with strict time, byte, and redirect limits.

1

URL Normalization

Host extraction, IDNA/UTS#46 to ASCII, redirect-safe canonicalization. Rejects private IPs, metadata ranges, and internal hostnames before any fetch.

2

Hardened Fetch

No cookies, no auth headers, strict time/byte/redirect limits. Preview images proxied through lesser.host CDN — origin never contacted directly by instance code.

3

Render (Optional)

Headless browser screenshot thumbnail + bounded text snapshot. Auto-escalation: render only for suspicious links, or always. Render artifacts shared across preview + safety.

4

Retention

Benign render artifacts retained 30 days. Flagged/suspicious evidence packs retained 180 days. Retention sweeper proves deletion on schedule.

AI Moderation

Instance-private moderation scanning. Implemented as a provider for Lesser's existing AI moderation hooks. Every scan is logged with requester identity and policy version.

Text Moderation

Language detection, entity extraction, PII scanning via AWS Comprehend. Structured output with categories, confidence scores, and content highlights.

Image Moderation

Moderation labels, text detection, face detection via AWS Rekognition. Configurable sensitivity thresholds per instance.

Trigger Policies

Default: on reports. Optional: always-on, links/media only, virality thresholds. Instance-configurable per service tier.

Audit & Privacy

Every scan logged with requester, policy version, and outputs. No results published as federation-wide attestations by default. Instance-private by design.

Claim Verification

Multi-model evidence extraction with structured citations and confidence scores. Costs are estimated up-front and charged only on cache miss.

Pipeline

Claim Extraction

Classifies claims as checkable vs. opinion. Extracts entities, relationships, and temporal constraints. Prepares structured verification queries.

Pipeline

Multi-Model Verification

Runs claims against multiple LLM providers with configured model sets. Each model produces independent verdicts with citations and confidence scores.

Output

Structured Attestation

Per-claim verdicts with citations, source URLs, and confidence. Results marked "inconclusive" when evidence is insufficient — no forced certainty.

Soul Registry & Identity

The soul registry anchors EqualToAI agent identity — combining on-chain ERC-721 anchors, off-chain state via TableTheory, S3 registration artifacts, and Safe-ready governance operations.

On-Chain

SoulRegistry.sol

ERC-721 soul tokens where tokenId == agentId (deterministic). Implements EIP-8004 getAgentWallet(uint256 agentId). Soulbound after claim window with signature-verified wallet rotation. Deployed on Base (8453).

Identity

Agent Identity

agentId = keccak256("normalizedDomain/normalizedLocalAgentId") as uint256. DNS TXT + HTTPS well-known proofs bind agents to domains. Registration signing via EIP-191 over JCS-serialized payload.

Policy

Hosted-Bound-Soul v1

Vocabulary: anchor state (hosted_offchain / immutable_onchain), operational binding (hosted_bound_soul), capability policy (email/phone/SMS/voice), and caller access/payment policy (x402 grants). Anchor state is assurance metadata — on-chain is not a prerequisite for comms.

Storage

Registration Artifacts

S3 versioned registration packs at registry/v1/agents/{agentId}/registration.json. Includes DNS/HTTPS proofs, wallet signatures, capability declarations, and MCP endpoint registration.

Soul Comm Mailbox Authority (ADR 0005)

Host Owns

Canonical Mailbox State

Delivery objects, provider/thread/idempotency facts, bounded encrypted content, content identity, and read/archive/delete state. This is the governed exception to host's metadata-only posture.

Body Exposes

MCP Facade Only

MCP tools call host's instance-authenticated mailbox APIs. Body must not persist durable mailbox truth locally. List endpoints return redacted previews; full content requires explicit read call with audit evidence.

Lesser Receives

Notification Projections

UX/activity summaries only — not authoritative. Idempotent by deliveryId. Portal list views read canonical state with list/content split enforced.

Tip Host Registry

On-chain host registration governance via the TipSplitter contract. Hosts register domains, set fees, and receive tip splits. All operations go through Safe multi-sig with audit trail.

1

Registration

External operators submit wallet signature + DNS TXT proof. Higher-assurance updates (wallet/fee changes) require both DNS + HTTPS well-known proofs. hostId = keccak256(normalize(domain)).

2

Safe Governance

lesser.host proposes registerHost, updateHost, setHostActive payloads. Operators execute via admin Safe. Token allowlist management for supported currencies.

3

Fee Structure

Lesser org fee: 1% (fixed). Host fee: configurable per-host, capped at 5% (500 bps). Actor receives remainder. Supported tokens: ETH, USDC, USDT, EURC, XAUt.

4

Audit & Reconciliation

Transaction hashes, receipts, and host registry state snapshots stored in DynamoDB. Events-only tip history — no on-chain tip storage. Pull-payment withdrawal model.

On-Chain Contracts

Solidity contracts under contracts/contracts/, built and tested with Hardhat. Non-upgradeable. Deployed on Base (8453) with admin Safe as owner.

Contract

TipSplitter.sol

Host registry, token allowlist, and pull-payment tip splitting. Methods: registerHost, updateHost, setHostActive, tipETH, tipToken, tipAgentETH, tipAgentToken. Emergency pause + stray sweep.

Contract

SoulRegistry.sol

ERC-721 with tokenId == agentId. EIP-8004 getAgentWallet. Soulbound after claim window. Signature-verified wallet rotation with per-agent nonce replay protection.

Contract

ReputationAttestation.sol

Owner-only publishRoot(bytes32 root, uint256 blockRef, uint256 count). latestRoot() returns (root, blockRef, count, timestamp). Used by soul-reputation-worker for on-chain reputation root publication.

Contract

ValidationAttestation.sol

Owner-only publishRoot for off-chain validation result snapshots. latestRoot() returns (root, blockRef, count, timestamp). Used by soul-reputation-worker for on-chain validation root publication.

Governance Infrastructure (GovTheory)

Deterministic governance verification under gov-infra/. Quality, security, and compliance checks that fail closed — never weakened to make checks pass.

SEC-1: Solidity SAST

Slither static analysis on all contracts under contracts/. Runs in a repo-local Python venv. No global installs required.

SEC-3: Supply Chain

Dependency scanning for Node, Go, and Python. Allowlist with mandatory justification comments in gov-infra/planning/lesser-host-supply-chain-allowlist.txt.

DES-1: Design Fidelity

Evidence captures comparing implemented UI against design contracts. Screenshots, markdown summaries, and fixture source references.

MAI-4: CI Integration

CI must run bash gov-infra/verifiers/gov-verify-rubric.sh and treat failures as merge blockers. Required for maintainability.

Verifier Contract

All verifiers are deterministic and fail closed. Missing or unimplemented checks record as BLOCKED. Gates are never relaxed by excluding directories or lowering thresholds.

Evidence Directory

Reports and logs under gov-infra/evidence/. Machine-readable JSON reports + operator-readable markdown summaries. Versioned in git alongside application code.

Credit System

Rule

Cache Hits Are Free

Results matching (normalizedURL, policyVersion) or (contentHash, module) never consume credits.

Rule

Non-Blocking

Exhausted credits return "not_checked" — publishes are never blocked by budget enforcement.

Rule

Author Discount

Initial publish from a registered instance receives discounted pricing on trust services.

Rule

No Rollover

Unused included credits do not roll over. Additional credits purchasable via Stripe checkout.
